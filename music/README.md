# Music

`theme.mp3` is the track the host screen's ♪ button plays and loops
(5:15, 128 kbps). Replace the file to change the music, or point
`MUSIC_URL` in `index.html` at a different filename.

The recording was supplied by the repo owner. It's a copyrighted work used
here for a private family party — not licensed for redistribution, so bear
in mind that a public repo serves it to anyone with the link. It plays on
the host device only, since that's the one attached to speakers.

Format: `.mp3` is the safe choice; `.m4a` and `.ogg` also work in most
browsers. Keep it under a few MB so GitHub Pages serves it quickly.
