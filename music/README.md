# Music

Drop an audio file here named **`theme.mp3`** and the host screen's
♪ button will play and loop it. Nothing else needs changing — or point
`MUSIC_URL` in `index.html` at a different filename.

No track is committed here. A Hedwig's Theme recording is someone else's
copyrighted work, so use a copy you're entitled to use (one you own, or a
licensed/royalty-free arrangement). It plays on the host device only, since
that's the one attached to speakers.

Format: `.mp3` is the safe choice; `.m4a` and `.ogg` also work in most
browsers. Keep it under a few MB so GitHub Pages serves it quickly.
